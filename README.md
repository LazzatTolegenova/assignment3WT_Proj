# Healthy — Advanced CSS project

English version of the 1FIT student project.

Pages:
- index.html — Home
- sports.html — Sports & activities overview (categories, weekly schedule, free-time story)
- services.html — Prices and activities catalogue
- locations.html — Studios/locations catalogue, booking form and FAQ

CSS:
- css/style.css — shared visual system, Flexbox and Grid
- css/responsive.css — responsive layouts for tablet and mobile

Open index.html in a browser or use Live Server in VS Code.
